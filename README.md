# ds4g-livable-streets-debt

## Background
This project focuses on the analysis of debt-based and non-road-safety-related suspensions in Massachusetts between 2020 and 2022 for the non-profit organization, Livable Streets Alliance. We manually classified all unique reasons for license suspension in the datasets we received and noted them as either debt-based or non-debt-based and as safety-related or non-road-safety-related or uncoded. 

## Technical Architecture
All code is present in a Jupyter Notebook file with various `CSV` and `Excel` files in the `data` folder that houses the data we used and classified for this project. Python and Pandas were the primary tools, but for the final deliverable, we used Tableau, which is not present in this repository and was instead sent directly to the client.

## How to Run
Download a recent version of [Python](https://www.python.org/downloads/) and also follow the download instructions for [Jupyter](https://docs.jupyter.org/en/latest/install/notebook-classic.html) after Python has been installed. Simple run all cells and the notebook should work fine. If there is a missing package, add it to the top line of the `.ipynb` file and re-run all following cells.
